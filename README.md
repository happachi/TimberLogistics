# TimberLogistics — Система учета движения древесины

**TimberLogistics** — это настольное приложение (Windows Forms), разработанное для автоматизации учета автотранспорта, поступления сырья (круглого леса) и расхода ГСМ на лесозаготовительном предприятии.

Система заменяет бумажные журналы, автоматизирует сложные расчеты объема древесины по ГОСТу и обеспечивает прозрачность логистических процессов на КПП.

---

## 🚀 Функциональные возможности

### 👮 Модуль "Сторож" (КПП)
*   **Регистрация рейсов:** Фиксация времени въезда и выезда машин.
*   **Приемка леса:** Ввод параметров груза (сортамент, высота, количество ставов).
*   **Автоматический расчет:** Мгновенный расчет плотного объема древесины (м³) на основе коэффициентов полнодревесности.
*   **Учет ГСМ:** Регистрация выдачи топлива с привязкой к водителю и машине.
*   **Фильтрация:** Поиск записей по датам, постам охраны и гос. номерам.

### 👨‍💼 Модуль "Администратор"
*   **Управление справочниками:** Транспорт, Водители, Экипажи, Типы леса, Посты охраны.
*   **Управление доступом:** Создание пользователей, назначение ролей и привязка сторожей к конкретным постам.
*   **Защита данных:** Валидация ввода, предотвращение создания дубликатов.

## ⚙️ Установка и запуск

### 1. Требования
*   Windows 10/11
*   MS SQL Server (Express или Full) 2019 и выше
*   SQL Server Management Studio (SSMS)
*   Visual Studio 2022 (для сборки проекта)

### 2. Развертывание Базы Данных
В репозитории находится файл **`TimberLogisticsDB_Script.sql`** (или `.bak`), содержащий структуру базы и тестовые данные.

1.  Откройте **SQL Server Management Studio (SSMS)**.
2.  Подключитесь к вашему локальному серверу (обычно `.\SQLEXPRESS` или `localhost`).
3.  Откройте файл скрипта: `File` -> `Open` -> `File...` -> выберите `.sql` файл из проекта.
4.  Нажмите кнопку **Execute** (или F5).
    *   *Скрипт автоматически создаст базу `TimberLogisticsDB`, таблицы и заполнит их демо-данными.*
5.  Если пункт 4 не сработал, изначально создайте пустую БД TimberLogisticsDB и повторите пункты 3-4.
   
### 3. Настройка подключения (Connection String)
Чтобы приложение увидело базу данных на вашем компьютере, нужно настроить строку подключения.

1.  Откройте проект в Visual Studio.
2.  В обозревателе решений найдите файл **`App.config`**.
3.  Найдите секцию `<connectionStrings>`.
4.  Измените параметр `Data Source` на имя вашего сервера:

```xml
<connectionStrings>
    <add name="TimberLogisticsDB.Properties.Settings.TimberLogisticsDBConnectionString"
         connectionString="Data Source=ВАШ_СЕРВЕР;Initial Catalog=TimberLogisticsDB;Integrated Security=True"
         providerName="System.Data.SqlClient" />
</connectionStrings>
